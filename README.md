# Folio Local

用喜欢的编辑器写 Markdown，在浏览器里随写随看。示例是一篇关于墨水分色的笔记，中文、英文和日文各有一份原文，共用一张原创示意图。

## 打开自己的 Markdown 文件夹

安装依赖后，在 Folio Local 目录运行一条命令。参数是作者文件夹本身，路径含空格时加引号。

```sh
pnpm open "D:/Writing/My Notes"
```

打开 http://127.0.0.1:4274/ 。工作台递归列出文稿，把同一篇的译本放在一起。点击文件旁的「预览」查看当前 Markdown 和插图，保存修改后页面自动更新。勾选译本、查看差异，再确认发布。本地只读内容源为 http://127.0.0.1:4275/ 。可用 `--port 4374` 指定工作台端口，公开服务使用下一个端口。每个内容目录有独立发布状态，存放在 Folio Local 的忽略目录中。

- 普通 `.md` 文件直接可用。标题依次取 frontmatter 的 `title`、正文一级标题或文件名。没有语言信息的文稿会显示「未标注语言」。
- `notes/rain.zh.md` 和 `notes/rain.ja.md` 会归为同一篇。`en/notes/rain.md` 也可以加入该组。语言优先取 frontmatter 的 `lang`，再取文件名后缀或目录中的语言代码。`cn` 识别为 `zh-CN`。
- 不同名字的译本可在 frontmatter 写相同的 `translationKey`，并分别填写 `lang`。同一组内语言重复时，工作台会标出冲突。
- 在 Markdown 里用相对路径引用文件夹内的 PNG、JPEG、GIF 或 WebP，包括同目录、子目录和上级目录中的附件。文件名有空格可写成 `![雨后的台阶](<../photos/stone steps.png>)`，也可使用 `%20`。发布只带选中译本实际引用的图片。
- 隐藏目录、隐藏文件、符号链接和 `node_modules` 会跳过。新增 Markdown 后工作台会自动发现。移动或删除本地文稿不会自动撤下已确认的公开版本。

## 第一次打开

需要 Node.js 22 或 24，以及 pnpm 9。克隆仓库后进入含有 `package.json` 的目录，运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址（通常是 http://127.0.0.1:5173）。首次安装需要网络下载依赖；安装完成后，写作与预览都在本机完成。启动无需账号、数据库或环境变量。

## 改一段，看看结果

用 Obsidian 打开 `content/`，或用任意文本编辑器打开下面的文件。保持浏览器预览页开着，在对应 Markdown 的第一段末尾加一句话并保存。页面会自动显示新文字。右上角的语言菜单可以切换同一篇笔记的译本。

| 译本 | 编辑文件 | 本地路由 |
| --- | --- | --- |
| 简体中文 | `content/index.md` | `/` |
| English | `content/en/index.md` | `/en/` |
| 日本語 | `content/ja/index.md` | `/ja/` |

图片位于 `content/assets/ink-study.png`，三个译本都通过相对路径引用它。复制整个 `content/` 目录，就能带走三份原文与原图。

## 静态预览

```sh
pnpm build
pnpm preview
```

产物位于 `.vitepress/dist/`。这一版用 VitePress 提供本地预览。静态构建会包含目录里的全部译本，请只把打算分享的内容放入待分发的构建。这里的命令只操作本机文件。

代码、示例文章和示意图采用 [MIT 许可证](LICENSE)。

## 发布到本地测试站

另开终端运行 `pnpm publish:local`，打开 http://127.0.0.1:4174/ 。首次启动，三个译本都是草稿。勾选译本，点击「查看差异」，核对 Markdown 增删行和图片变化，再点击「确认发布到本地测试站」。在 http://127.0.0.1:4175/ 查看读者能看到的版本。

| 工作台状态 | 含义 |
| --- | --- |
| 草稿 | 这个译本尚未进入测试站 |
| 已发布 | 正文、元数据和引用的图片与测试站一致 |
| 有未发布修改 | 测试站保留上一次确认的版本，当前文件有变化 |

编辑器保存只更新写作预览。检查之后再改正文或替换图片，确认时会要求重新对照。关闭服务后，发布状态保存在当前项目的 `.folio-local/`，下次启动继续使用。该目录由 Git 忽略。`pnpm build` 仍用于全目录静态预览。

## 让另一个网站读取已发布内容

启动本地发布服务后，接入方使用 `GET http://127.0.0.1:4175/api/v1/published`。响应包含 `schemaVersion: 1`、当前发布序号 `generation` 和已发布译本数组 `editions`。每项提供 `id`、`lang`、`label`、`title`、渲染好的 `html`、`version` 与去重的 `images`。从同一公开服务的 `/assets/<图片编号>` 下载图片；编号的文件名部分是 SHA-256。HTML 中的图片路径相对于公开服务根目录。生成独立站点时，将图片一并保存并改写为站内链接。

读取清单时可以保存响应头 `ETag`，后续通过 `If-None-Match` 发起条件请求。未发生发布时返回 304。编辑草稿不改变清单或 ETag。接入方无需管理员凭据。
